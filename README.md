# ShopFlow - QA Engineering Portfolio

**Practical QA Engineering Project | Work in Progress**

## About

This repository is my practical QA Engineering portfolio.

The project demonstrates hands-on skills in manual Web testing, REST API testing, test design, SQL, defect reporting and API test automation.

**Application:** ShopFlow — educational e-commerce application.

**Role:** QA Engineer.

**Learning goal:** Build practical skills required for a Junior / Junior+ QA Engineer position.
